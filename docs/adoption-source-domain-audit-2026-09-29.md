# Adoption source domain audit — 2026-09-29

Read-only HTTP sample from each source domain in the 2,394-pet production feed. TypeSafe Jev reviewed each domain's host, final host, response, and page title. LLM labels are triage only; they do not certify a website or pet identity. Individual link checks covered 469 distinct URLs. See `scripts/audit-adoption-links.py` for reproducible HTTP and pet-ID checks.

The URL audit found 438 HTTP 200 responses, 22 non-200 responses, and 9 network failures. Of 350 pet-route URLs, 339 showed both the expected animal ID and name in returned HTML. Ten RescueGroups pet routes redirected to `/clientsitedown` with HTTP 200. One Shelterluv route was a generic adoption form. Generic organization links are never presented as pet listings.

The code suppresses 182 affected pet links across three unrelated or placeholder domains, the RescueGroups site-down routes, and 20 failed URL paths. Another 93 pets had no source link in the feed. The remaining 339 direct pet links are labeled as pet listings; 1,780 generic links are labeled as organization websites. These counts describe this feed snapshot, not permanent availability. An HTTP 403 may reflect bot blocking, so it was not automatically suppressed.

The unrelated page at `collierpets.com` displayed Chinese gambling content. `basv.org` and `unitedhope4animals.org` displayed placeholder pages. [RescueGroups API documentation](https://api.rescuegroups.org/v5/public/docs) identifies animal IDs as a first-party field and supports direct animal records. Link identity checks use the feed's external ID and returned page content; they do not prove that an animal is still available.
